# Input

This program does not take any user input. Instead, it uses hardcoded string
values defined directly in the source code: the developer's name
(Yashasree Duggiempudi), degree program (Computer Science), and school
(City University of Seattle). These values act as static data that the
program uses to generate its output.

# Process

The app is built using five React Native components: one `View`, three
`Text` elements, and `StyleSheet`. The `View` component acts as a
container that holds the three `Text` elements, arranging them vertically
in the center of the screen. `StyleSheet.create()` defines the visual
styling, including a yellow background color, centered alignment, and
font sizing for the text. React Native then renders these components
into a mobile-friendly UI.

# Output

The final output is a mobile screen with a solid yellow background
displaying three centered lines of black text: the developer's name,
degree program, and school. This matches the required design shown in
the assignment's example screenshot.
